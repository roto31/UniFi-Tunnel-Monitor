Install complete

The LaunchDaemon is loaded and the menu bar app is in /Applications.

  1. Open Tunnel Monitor from /Applications — it lives in the menu bar.
  2. Click Edit Config and set SMTP_PASSWORD (iCloud app-specific password).
  3. Click Test Email and Test Notify to verify alert paths.
  4. Click Copy SSH Auth Cmd, then paste in Terminal and run it once to authorize this Mac on the UDR7 for dedup checks. Then click SSH Test.
  5. Click Force Check to trigger an immediate health check.

The first banner notification may be silently dropped by macOS. Open System Settings → Notifications, find Script Editor / osascript, and enable banners.
