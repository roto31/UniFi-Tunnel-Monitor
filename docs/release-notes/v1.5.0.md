## Tunnel Monitor v1.5.0

Opt-in spoke policy-route visibility, plus a checker the Mac can install on the spoke. v1.4.0 was not published as its own GitHub release; those changes are included here.

### Added

- Mac status card for an optional spoke policy route (`SPOKE_POLICY_ENABLED`, default off). One SSH read after the tunnel ping succeeds. Advisories are menu and one banner only — no email, and `diagnosis` is unchanged. See [Usage guide](https://github.com/roto31/UniFi-Tunnel-Monitor/blob/v1.5.0/docs/tunnel-monitor/04-usage-guide.md).
- **Install Checker** (`tunnel-check --spoke-install-checker`) copies `spoke-policy-check.sh` to the spoke and writes `/data/tunnel-monitor/policy-state` every 5 minutes. Setup field **Policy source prefix** (`SPOKE_POLICY_SOURCE_CIDR`). See [Placeholders](https://github.com/roto31/UniFi-Tunnel-Monitor/blob/v1.5.0/PLACEHOLDERS.md).
- **Spoke SSH Test**.

### Changed

- A healthy tunnel with a spoke advisory is yellow and no longer shows "Down for …" from an old alert timestamp.
- Gateway diagnostics print OpenVPN status when IPsec has no security associations. `heal.sh` is unchanged and stays off.
