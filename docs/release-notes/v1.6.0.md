## Tunnel Monitor v1.6.0

A VPN speed card in the menu, fed by an optional speed check on the Mac.

### Added

- **VPN speed** card: `Down X Mbps · Up Y Mbps · RTT Z ms · <time>`, the method in small text, and `(older than 12 h)` when the result is stale. Read from `/opt/tunnel-monitor/speed.json` beside `state.json`. Shown only when a speed check is installed. See [Usage guide](https://github.com/roto31/UniFi-Tunnel-Monitor/blob/v1.6.0/docs/tunnel-monitor/04-usage-guide.md#vpn-speed-160).
- **Run speed test now** writes the trigger file `/opt/tunnel-monitor/speed-request` (no admin password) and shows **Test requested…** until a new result arrives.

### Unchanged

- A missing, malformed or stale `speed.json` never changes the traffic light, `diagnosis`, email, the "state.json unreadable" message, or the widget.
